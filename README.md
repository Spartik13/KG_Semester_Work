# KG_Semester_Work

# Моделирование тумана

Курсовой проект по компьютерной графике: приложение для исследования моделей тумана в трёхмерной сцене.

**Текущая версия — альфа.** Реализована линейная модель тумана с настройкой параметров в реальном времени.

## Возможности

- Трёхмерная сцена с полом, кубами и цилиндрами на разных расстояниях от камеры.
- Свободное перемещение и поворот камеры.
- Изменение цвета тумана.
- Настройка начальной и конечной дистанции линейного тумана.
- Включение и выключение тумана.
- Отображение текущих параметров в строке состояния.

Туман рассчитывается во фрагментном шейдере: цвет поверхности после освещения смешивается с цветом тумана в зависимости от расстояния до камеры.

## Технологии

- C++17
- wxWidgets 3.2 — графический интерфейс
- OpenGL 3.3 Core — трёхмерная графика
- GLSL — шейдеры освещения и тумана
- GLEW — загрузка функций OpenGL
- CMake — система сборки

## Управление

Для управления камерой наведите курсор на область сцены.

| Действие | Управление |
|---|---|
| Движение вперёд и назад | W / S |
| Движение влево и вправо | A / D |
| Движение вниз и вверх | Q / E |
| Поворот камеры | Удержание левой кнопки мыши и перемещение |
| Движение вперёд и назад | Колесо мыши |

Параметры тумана изменяются на панели справа.

## Сборка и запуск

Проект проверен в Windows с использованием CLion и MinGW из MSYS2.

Для сборки необходимы:

- компилятор с поддержкой C++17;
- CMake версии 3.16 или новее;
- wxWidgets 3.2 с поддержкой OpenGL;
- GLEW;
- драйвер видеокарты с поддержкой OpenGL 3.3 Core.

Откройте проект в CLion и настройте компилятор MinGW. В `CMakeLists.txt` путь к библиотекам MSYS2 по умолчанию указан как `C:/msys64/mingw64`. При необходимости измените параметр `MINGW_ROOT`.

Для запуска необходимые DLL должны быть доступны программе, например через добавление `C:/msys64/mingw64/bin` в переменную `PATH`.

## Структура проекта

| Компонент | Назначение |
|---|---|
| `MainFrame` | Главное окно и панель параметров |
| `ScenePanel` | Контекст OpenGL, обработка ввода и перерисовка |
| `Scene` | Хранение объектов и отрисовка сцены |
| `SceneObject` | Базовый класс объектов сцены |
| `Mesh` | Генерация геометрии и работа с графическими буферами |
| `Camera` | Положение, движение и поворот камеры |
| `FogModel`, `LinearFog` | Хранение параметров тумана и передача их в шейдер |
| `ShaderProgram` | Компиляция шейдеров и передача параметров |
| `MathUtils` | Операции с векторами и матрицами |

## Планы развития

- Настройка плотности тумана.
- Сохранение параметров.
- Экспорт скриншотов для сравнения моделей.

В альфа-версии кнопки «Сохранить» и «Скриншот» пока выводят информационное сообщение в строке состояния.

# KG_Semester_Work

# Моделирование тумана

Курсовой проект по компьютерной графике. Приложение позволяет сравнивать модели тумана в трёхмерной сцене.

**Текущая версия — бета.** Доступны линейная, экспоненциальная и квадратичная экспоненциальная модели тумана.

## Возможности

- Трёхмерная сцена с полом, кубами и цилиндрами на разных расстояниях от камеры.
- Свободное перемещение и поворот камеры.
- Изменение цвета тумана.
- Настройка начальной и конечной дистанции линейного тумана.
- Настройка плотности экспоненциальных моделей тумана.
- Включение и выключение тумана.
- Отображение текущих параметров в строке состояния.
- Сохранение и загрузка параметров в файлах `.fog`.
- Экспорт 3D-сцены в PNG.

Туман рассчитывается во фрагментном шейдере. Цвет освещённой поверхности смешивается с цветом тумана в зависимости от расстояния до камеры.

## Технологии

- C++17
- wxWidgets 3.2 — графический интерфейс
- OpenGL 3.3 Core — трёхмерная графика
- GLSL — шейдеры освещения и тумана
- GLEW — загрузка функций OpenGL
- CMake — система сборки

## Управление

Для управления камерой наведите курсор на область сцены.

| Действие | Управление |
|---|---|
| Движение вперёд и назад | W / S |
| Движение влево и вправо | A / D |
| Движение вниз и вверх | Q / E |
| Поворот камеры | Удержание левой кнопки мыши и перемещение |
| Движение вперёд и назад | Колесо мыши |

Параметры тумана изменяются на панели справа. Кнопки «Сохранить» и «Загрузить» работают с файлами настроек. Кнопка «Скриншот» сохраняет изображение 3D-сцены.

## Сборка и запуск

Проект проверен в Windows с использованием CLion и MinGW из MSYS2.

Для сборки необходимы компилятор с поддержкой C++17, CMake 3.16 или новее, wxWidgets 3.2 с поддержкой OpenGL и GLEW. Для запуска нужен видеодрайвер с поддержкой OpenGL 3.3 Core.

Откройте проект в CLion и настройте компилятор MinGW. В `CMakeLists.txt` путь к wxWidgets по умолчанию указан как `C:/msys64/mingw64`. В параметрах CMake задайте `MINGW_ROOT` и `CMAKE_PREFIX_PATH` с путём к среде MSYS2, из которой установлены компилятор и библиотеки.

Для запуска добавьте папку `bin` выбранной среды MSYS2 в `PATH` конфигурации запуска.

## Структура проекта

| Компонент | Назначение |
|---|---|
| `MainFrame` | Главное окно, панель параметров и файловые диалоги |
| `ScenePanel` | Контекст OpenGL, обработка ввода, перерисовка и экспорт PNG |
| `Scene` | Хранение объектов и отрисовка сцены |
| `SceneObject` | Базовый класс объектов сцены |
| `Mesh` | Генерация геометрии и работа с графическими буферами |
| `Camera` | Положение, движение и поворот камеры |
| `FogModel`, `LinearFog`, `ExpFog`, `Exp2Fog` | Хранение параметров тумана и передача их в шейдер |
| `ShaderProgram` | Компиляция шейдеров и передача параметров |
| `SceneShaders.h` | Исходный код вершинного и фрагментного шейдеров |
| `MathUtils.h` | Операции с векторами и матрицами |
